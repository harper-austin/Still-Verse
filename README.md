# Still

**A small, calming verse-card app.** Open it when you want a quiet moment: tap or click the card, or swipe, to see another one.

The colors are warm cream, forest green, and earthy brown. There are no accounts or extra features.

## A note about the words on the cards

This is an early visual prototype. The card text is sample placeholder writing, **not Bible quotations and not ESV Scripture**. The Bible references are examples too. The app does not yet connect to a Bible text service.

## Try it on your computer

Open `index.html` in a web browser. You do not need to install anything.

## Share it online

The app can be published as a simple website with GitHub Pages. See [GITHUB-PUBLISH.md](GITHUB-PUBLISH.md) for the step-by-step guide. Once published, GitHub gives you a web address you can share.
